# 🌍 Geoprojetos - Capacitação em Python e Geoprocessamento

Este repositório contém exercícios práticos de capacitação em bibliotecas como **NumPy**, **SciPy**, **Pandas**, **Matplotlib** e **GeoPandas**, com foco na manipulação e organização de dados espaciais — especialmente no contexto de desastres ambientais e mudanças climáticas.

## Objetivos do Projeto

- Praticar o uso de bibliotecas de ciência de dados e geoprocessamento.
- Demonstrar domínio básico de versionamento com Git e GitHub.
- Criar repositórios organizados e reutilizáveis para análise espacial.
- Trabalhar com dados espaciais integrados a Sistemas de Informação Geográfica (SIG).

## Estrutura do Repositório


├── data/          # Dados brutos (mantido vazio no GitHub, os dados brutos podem ser  baixados no Google Drive) 
├── outputs/       # Resultados e saídas geradas (mantido vazio no GitHub, apenas para referencia)
├── notebooks/     # Cadernos Jupyter com análises passo a passo
├── scripts/       # Scripts Python organizados por tarefa
└── README.md      # Este arquivo


**Nota:** Os dados brutos e de saída estão armazenados fora do repositório, no [Google Drive](#) para evitar sobrecarga no versionamento.


## 🧰 Tecnologias Utilizadas

- Python 3.10 (Anaconda)
- Jupyter Notebooks
- GeoPandas
- Pandas
- NumPy
- SciPy
- Matplotlib
- Git e GitHub



## 🚀 Como Executar

1. Clone este repositório:
   bash
   git clone https://github.com/lg-mn/geoprojetos.git


2. Crie um ambiente virtual (opcional).
3. Instale as dependências:

   bash
   pip install -r requirements.txt
 
4. Acesse os notebooks e scripts normalmente.
